## ⚙️ 4. Tips Teknis Cetak & Pembuatan QR Code (Anti Gagal)

1. **Gunakan Dynamic Link Pendek:**
   - Link asli Play Store memiliki panjang 70+ karakter. Jika langsung dibuat QR Code, titik pixelnya akan sangat padat (*dense*). Kamera HP low-end akan butuh waktu lama untuk fokus.
   - Dengan menggunakan `s.id/manggapos` (hanya 14 karakter), QR code memiliki modul grid besar (Version 2 QR), sehingga dapat discan dalam **0,3 detik** meski dari jarak jauh.
2. **Kontras Warna Wajib Tinggi:**
   - Titik QR code harus **Hitam Pekat `#000000`** di atas latar belakang **Putih Bersih `#FFFFFF`**.
   - Hindari membuat QR code berwarna abu-abu muda, kuning, atau diletakkan di atas background gambar berpola karena sensor kamera HP murah tidak akan bisa membaca garis batasnya.
3. **Ukuran Fisik Minimum QR Code Saat Dicetak:**
   - Pada Kartu Nama: Minimal **2 x 2 cm** (Rekomendasi **2,5 x 2,5 cm**).
   - Pada Stiker Meja: Minimal **2,5 x 2,5 cm** (Rekomendasi **3 x 3 cm**).
   - *Safe Zone (Quiet Zone):* Sisakan jarak kosong putih minimal 3 mm di sekeliling kotak QR code.
4. **Uji Coba Lapangan Sebelum Cetak Massal:**
   - Selalu cetak 1 lembar sampel di kertas HVS biasa lewat printer rumahan.
   - Nyalakan kamera HP Android termurah (misal HP kasir toko kerabat), redupkan lampu ruangan, lalu coba scan dari jarak 30 cm.
   - Jika langsung membuka halaman Google Play Store Mangga POS dalam 1 detik, desain Anda sudah **100% Siap Cetak Massal**!
