# Component Specifications

Standard component styling guidelines adopting the design system tokens.

### 1. Primary Button
- **Background:** `#0070fc` (`var(--primary)`)
- **Hover:** `#005ecc` (`var(--primary-hover)`)
- **Text:** `#ffffff`, font-weight 600
- **Border Radius:** `8px` (`rounded-md`)
- **Padding:** 10px 16px (compact) / 12px 20px (standard)
- **Shadow:** `0 1px 2px 0 rgba(0, 112, 252, 0.2)`

### 2. Secondary Button
- **Background:** `#ffffff`
- **Border:** 1px solid `rgba(26, 26, 26, 0.12)`
- **Hover:** `#f8fafc` with border `rgba(26, 26, 26, 0.24)`
- **Text:** `#1a1a1a`, font-weight 600
- **Border Radius:** `8px` (`rounded-md`)

### 3. Cards & Panels
- **Background:** `#ffffff` (`var(--surface)`)
- **Border:** 1px solid `rgba(26, 26, 26, 0.12)`
- **Border Radius:** `8px` (`rounded-md`)
- **Shadow:** Subtle diffused `0 1px 3px 0 rgba(26, 26, 26, 0.04)`

### 4. Form Inputs
- **Background:** `#ffffff`
- **Border:** 1px solid `rgba(26, 26, 26, 0.12)`
- **Focus Border:** `#0070fc` (`var(--primary)`), ring 2px with `rgba(0, 112, 252, 0.15)`
- **Border Radius:** `8px` (`rounded-md`)
- **Padding:** 10px 14px
- **Text:** `#1a1a1a`, placeholder `#94a3b8`

### 5. Badges & Tags
- **Success:** Background `#e6f4ff`, text `#0070fc` or `#005ecc`, border `rgba(0, 112, 252, 0.2)`
- **Warning:** Background `#fef8e7`, text `#ba8c02`, border `rgba(186, 140, 2, 0.2)`
- **Danger:** Background `#f0f7ff`, text `#3294f5`
- **Radius:** `9999px` (Pill) or `4px` (Subtle tag)
