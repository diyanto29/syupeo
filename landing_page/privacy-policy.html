Tentang Aplikasi Ini

Syupeo adalah platform rantai pasok tertutup (closed-loop supply chain) yang menghubungkan Mitra Toko Ritel & UMKM dengan jaringan gudang Syupeo untuk kulakan barang langsung harga pabrik, dilengkapi aplikasi kasir POS gratis.

1

Informasi yang Kami Kumpulkan

Kami mengumpulkan informasi minimum yang diperlukan untuk menjalankan layanan Syupeo secara aman dan efektif.

Kategori Data Detail Kapan Dikumpulkan
Data Akun Nama lengkap, alamat email, nomor telepon, nama toko Saat registrasi akun
Data Transaksi Riwayat penjualan kasir, kulakan barang, mutasi kas, data shift Saat menggunakan fitur POS & kulakan
Data Inventori Daftar produk, stok, harga, barcode toko Anda Saat mengelola produk
Data Lokasi Koordinat GPS toko (hanya satu kali saat setup) Saat aktivasi akun mitra — untuk routing kulakan
Data Perangkat Model perangkat, versi OS, token notifikasi push Otomatis saat aplikasi pertama dijalankan
Log Penggunaan Waktu login, fitur yang diakses, error crash Selama menggunakan aplikasi

Kami TIDAK mengumpulkan

Kontak telepon, galeri foto, rekaman audio/video, riwayat browser, atau data dari aplikasi lain di perangkat Anda.

2

Bagaimana Kami Menggunakan Data

Setiap data yang kami kumpulkan digunakan secara spesifik untuk keperluan operasional Syupeo:

  • Mengelola akun dan autentikasi pengguna (kasir, owner toko, staf gudang)
  • Memproses dan mencatat transaksi penjualan kasir (POS)
  • Memfasilitasi pemesanan dan pengiriman kulakan dari gudang Syupeo ke toko mitra
  • Sinkronisasi stok otomatis antar kasir dalam satu toko
  • Mengirim notifikasi push tentang pesanan, stok habis, dan pengumuman penting
  • Menghasilkan laporan penjualan dan keuangan untuk owner toko
  • Mendeteksi dan memperbaiki bug/crash pada aplikasi
  • Verifikasi identitas dan kepatuhan terhadap regulasi
3

Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak ketiga manapun.

Data Anda dapat dibagikan hanya dalam kondisi berikut:

  • Penyedia infrastruktur: Supabase (PostgreSQL) sebagai penyedia database terenkripsi — tunduk pada standar keamanan SOC 2. Data disimpan di server Asia Tenggara.
  • Kewajiban hukum: Jika diwajibkan oleh peraturan perundang-undangan Indonesia yang berlaku atau perintah pengadilan.
  • Keselamatan pengguna: Jika diperlukan untuk mencegah penipuan atau aktivitas berbahaya yang merugikan mitra toko.

Catatan Penting

Semua mitra bisnis kami yang mengakses data Syupeo terikat perjanjian kerahasiaan data (NDA) dan hanya boleh menggunakan data sesuai tujuan yang telah disepakati.

4

Keamanan Data

Kami menerapkan langkah-langkah keamanan teknis dan organisasional yang ketat:

  • Enkripsi data in-transit menggunakan TLS 1.3
  • Enkripsi data at-rest pada semua database Supabase (PostgreSQL)
  • Row Level Security (RLS) — setiap pengguna hanya dapat mengakses data tokonya sendiri
  • Autentikasi berbasis JWT dengan masa berlaku token terbatas
  • Audit log akses untuk semua perubahan data sensitif
  • Pembaruan keamanan rutin pada semua dependensi aplikasi

Meskipun kami berupaya keras melindungi data Anda, tidak ada sistem yang 100% kebal dari ancaman. Harap gunakan kata sandi yang kuat dan jaga kerahasiaan akun Anda.

Retensi & Penghapusan Data

Kami menyimpan data Anda selama akun Anda aktif dan untuk periode berikut setelah akun ditutup:

  • Data transaksi kasir & kulakan: 5 tahun (kewajiban pembukuan usaha sesuai UU No. 8/1997)
  • Data profil akun: Dihapus dalam 30 hari setelah permohonan penghapusan akun
  • Log aplikasi & crash report: 90 hari rolling
  • Data lokasi toko: Dihapus bersamaan dengan profil akun

Untuk mengajukan penghapusan akun, kunjungi halaman Hapus Akun kami.
