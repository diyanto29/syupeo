# Syupeo Super Admin Web

Portal manajemen super admin dan merchant partner untuk ekosistem **Syupeo** berbasis **Next.js 16**, **Tailwind CSS**, dan **Supabase**.

- **Dashboard Kemitraan**: Verifikasi mitra toko ritel, status onboarding, dan pelacakan Starter Kits.
- **Master Katalog & Multi-Satuan**: Manajemen 32.000+ barcode ritel (PCS, RENCENG, PACK, DUS).
- **Gudang & Pengiriman**: Dispatch pesanan kulakan ke mitra toko berdasarkan zonasi wilayah & radius geofencing.
- **CRM & Lisensi**: Pengelolaan lisensi toko, perpanjangan masa aktif, dan analitik penjualan.

## Menjalankan Web Admin

```bash
cd admin_web
npm install
npm run dev
```
Buka browser di `http://localhost:3000`.
